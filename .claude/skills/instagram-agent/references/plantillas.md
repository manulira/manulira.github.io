# Plantillas de entrega

Usa estos formatos tal cual para que el contenido quede listo para copiar y publicar.

---

## Post (foto única o carrusel)

```
POST — [Pilar] · [Formato: Foto 4:5 | Carrusel N láminas]
Objetivo: [alcance | guardados | visitas | tienda | eventos]

VISUAL
[Descripción de la foto: sujeto, fondo, luz, encuadre, props. En paleta Sepia.]

LÁMINAS (solo carrusel)
1. [Gancho — máx. ~8 palabras]
2. ...
N. [CTA]

CAPTION
[Primera línea que funciona sola]
[Cuerpo — corto o con historia]
[CTA]

HASHTAGS
#SepiaCoffee #... (5–8)

ALT TEXT
[Descripción literal de la imagen para accesibilidad]

MEJOR HORARIO SUGERIDO
[p. ej. mar–jue 8:00–9:30 o 18:00–20:00, hora de Santiago]
```

## Reel

```
REEL — [Pilar] · [Duración objetivo] · 9:16
Hook (0–1.5 s): [qué se ve / texto en pantalla]

| Tiempo | Plano | Acción | Texto en pantalla |
|---|---|---|---|
| 0:00–0:01.5 | Primer plano | ... | ... |
| ... | ... | ... | ... |

AUDIO: [tipo de audio / sonido ambiente]
PORTADA: [frame + texto de portada, legible en grid 1:1]
CAPTION: [...]
HASHTAGS: [...]
```

---

## Stories

```
STORIES — [Tema] · N frames
1. Fondo [crema/carbón] · [Contenido] · Sticker: [ninguno | encuesta | pregunta | link | cuenta regresiva]
2. ...
```
